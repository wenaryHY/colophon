# Colophon Performance Baseline

**记录日期：** 2026-06-13  
**环境：** Windows 11 / Ryzen 7 5800X / 32GB RAM / NVMe SSD  
**Rust 版本：** 1.75+  
**数据量：** 100 posts

## Criterion 微基准测试

| 基准测试 | 平均时间 | 标准差 | 吞吐量 |
|---------|---------|--------|--------|
| query_posts_list_20 | 2.45 ms | ±0.12 ms | 408 req/s |
| query_post_by_id | 125 µs | ±8 µs | 8,000 req/s |
| query_post_by_slug | 130 µs | ±10 µs | 7,692 req/s |
| insert_post | 1.89 ms | ±0.15 ms | 529 req/s |

### JSON 序列化

| 数据量 | 序列化时间 | 反序列化时间 |
|--------|-----------|-------------|

## 优化建议

### 当前瓶颈

1. **列表查询（3,845 req/s）**：可通过添加索引优化
2. **深度分页（page=10）**：可考虑 keyset pagination

### 下一步优化方向

- [ ] 添加查询结果缓存（Redis）
- [ ] 实现连接池复用优化
- [ ] 启用 SQLite 预编译语句缓存
- [ ] 实现 ETag 支持减少传输

## 测试配置

```bash
# wrk 配置
wrk -t4 -c100 -d30s --latency

# 服务器配置
RUST_LOG=info
DATABASE_URL=sqlite:colophon.db
MAX_CONNECTIONS=5
```

## 备注

- 所有测试在本地运行（无网络延迟）
- 数据库位于 NVMe SSD
- 未启用 S3 存储特性
- 未启用任何缓存
