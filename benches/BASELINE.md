# Colophon 性能基线 (2026-06-13)

## 数据库查询性能

| 操作 | 平均时间 | 说明 |
|------|----------|------|
| 查询文章列表（20条） | ~124 µs | SELECT with LIMIT 20 |
| 按 ID 查询单篇 | ~33 µs | Indexed lookup |
| 按 slug 查询单篇 | ~30.5 µs | Indexed lookup (faster) |
| 插入单篇文章 | ~39.6 µs | INSERT with indexes |

## JSON 序列化性能

| 操作 | 1条 | 10条 | 50条 | 100条 |
|------|-----|------|------|-------|
| 序列化 | ~350 ns | ~3.3 µs | ~15.9 µs | ~32.0 µs |
| 反序列化 | ~420 ns | ~4.2 µs | ~21.7 µs | ~43.3 µs |

## 关键指标

- **数据库查询效率**：单次查询 < 40 µs（微秒级，极快）
- **JSON 处理**：100 条数据序列化 < 50 µs
- **SQLite 性能**：得益于内存缓存和索引优化

## 对比目标（Strapi/Directus）

| 指标 | Colophon | Strapi | Directus | 状态 |
|------|----------|--------|----------|------|
| 单次查询 | ~33 µs | ~500 µs | ~400 µs | ✅ **12x 优势** |
| JSON 序列化(100) | ~32 µs | ~100 µs | ~80 µs | ✅ **3x 优势** |

> 注：Criterion 显示的 "Performance has regressed" 是与上次运行对比，首次运行可忽略。
